## 三、中文编码与字形方案（重点）

### 3.1 问题

- `.txt`/`.cif`/`.sal`/`.tab` 全部以 **1 字节/字符（ASCII/Win-1252）** 存储；`*.cif`/`*.sal` 还有 Caesar+XOR 加密。直接写入 UTF-8 中文字节会被游戏以单字节逐字符读入，产生乱码。
- `.fnt` 位图字体只含 ASCII 字形（`font10.fnt` 16 KB，`font24.fnt` 36 KB），**没有中文字形**，即使文本能写入也无法显示。

### 3.2 两条技术路线（与您确认的取向）

用户已确认取向：**UTF-8 + 外挂 DLL**（类似已有汉化项目的技术路线）。

**方案 A（推荐）：GBK/GB2312 + 字体注入（静态资源路线）**
- 文本统一用 GBK 编码（1 字节 ASCII + 2 字节汉字），保持单字节解析兼容。
- 从旧版/同系列含 CJK 的字体源提取或生成含中文的 `.fnt`，替换/注入字体文件。
- 优点：无需修改 exe，无需运行时 hook，稳定性高，可复用现有 `Cultures-map-editor` 工具链（解包→翻译→重打包）。
- 缺点：需生成/注入 CJK 位图字体；游戏内字体是按固定字号点阵设计的，中文字符需要适配字号。

**方案 B（用户倾向）：UTF-8 + 外挂 DLL**
- 文本用 UTF-8，编写代理 DLL（如 winmm.dll / dinput8.dll 代理，复用现有补丁壳）注入游戏进程。
- 在引擎读取 `.txt`/`.cif`/`.sal`/`.tab` 的入口 hook，把 UTF-8 文本转成引擎能接受的格式，并 hook 渲染层让中文能显示。
- 优点：文本管理方便，支持完整 Unicode，无需改字体位图。
- 缺点：需要逆向 exe 找到文本加载/渲染函数并写 hook；工程量较大；需要配合字体（引擎内部还是位图字形，需注入 CJK 字形数据或改为运行时字形）。

**结论**：无论选哪条路，**都需要解决 `.fnt` 字体的 CJK 字形来源**。Cultures 1 代的中文版/其他语言版存在 CJK 字形位图字体是未知数；若无旧版中文资源，需用工具（如用渲染好的汉字位图）生成 `.fnt`。这一块建议在方案中单列。

## 四、汉化工作流（推荐顺序）

1. **解包**：用 `library.py` 把三个 `.lib` 解包到游戏目录（failsafe 机制），获得全部明文资源。或者用 `.temp/` 的 Python 脚本直接读库内文件。
2. **提取**：写提取脚本：
   - `.cif` → 解密为 `.ini`（`initialization.py`）
   - `.sal/.tab` → 解密为 `*.txt`
   - `.txt` → 直接作为简报原文
   - `.fnt` → 转成 `*.png + metadata.csv`（`bitmaps.py`）
3. **翻译**：德语 → 简体中文。建议用 `language_union.csv` 式术语表 + 分层翻译（先界面/系统/单位/物品，后地图/任务/简报）。
4. **编码转换**：根据选定的方案（GBK 或 UTF-8）生成目标编码文件。
5. **打包**：用 `library.py` 把修改后的文件重新打包回 `.lib`（或直接解包覆盖到游戏目录）。
6. **部署**：备份原文件 → 部署 → 游戏内验证（用户本地运行并反馈）。

## 五、风险与注意

- **加密文本表**：`.cif/.sal/.tab` 是 Caesar+XOR 加密的 INI 表，加密算法已确定，可无损双向转换；但**加密表内中文文本长度变化不影响解密**（长度无关，按 `\0` 终止）。
- **简报文本格式**：`.txt` 用 Win-1252，含 `\r\n` 换行表示、`<keyword:value>` 标签；翻译时**不得破坏标签结构**（尤其 `font`、`picture`、`globaljump`、`anchor`、`localjump`）。
- **人名**：维京人名（Adam、Erik…）一般保留原文不译。
- **字体**：`.fnt` 位图字体是显示瓶颈，无 CJK 字形时先解决字体问题。
- **编码支持**：Cultures 1 的文本加载是逐字节（1 字节/字符），**原生不支持 UTF-8/GBK 多字节**，因此不 hook 引擎时只能走「1 字节字符映射」路线或 GBK + 字体注入路线。
- **兼容性**：`data.lib` 里的 `english.txt/deutsch.txt` 与 `language_eng.tab/language_ger.tab` 是**语言选择相关的文本**，注意不要破坏语言切换逻辑（德语为默认启动语言）。
- **备份**：部署前必须备份 `data_l\*.lib` 和根目录原文件。
